TaskOS is a operating system with its own kernel on top of Intel/AMDs x86_64 architecture\.
This is currently just plans, assembly files, ANSI-C files, and that.

Nothing here is compiled, so you would have to do that yourself, nor is anything in a bootable setting yet.

The image below shows an example of what the desktop (should) look like when the first version close to being finished\.
There is plans to add a blur theme, but it's being started off as a classic theme, only for testing.
