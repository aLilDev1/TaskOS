# ***TaskOS***
![](github/logo.png)

TaskOS is a operating system ontop of the Linux kernel, stand-alone from any other distributions\.
This is currently just plans, and a few .C and .H files, and that's about it.

Nothing here is compiled, so you would have to do that yourself, and it is not properly configed
to boot correctly with Linux.

The image below shows an example of what the desktop (should) look like when this is being close to finish\.
There is plans to add a blur theme, but it's being started off as a classic theme, just for testing.
